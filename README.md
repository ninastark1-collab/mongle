# PIKK. — 오늘의 픽, 내일 문 앞에

오늘 고르고, 내일 받는 라이프스타일 마켓. 순수 HTML/CSS/JavaScript로 만든 **학습용 쇼핑몰 데모**입니다.

## 기능
- **구매자**
  - 상품 찾기: 목록·검색(자동완성/최근 검색어)·필터·정렬, 상품 상세, 찜
  - 결제: 장바구니(무료배송까지 남은 금액 표시), 쿠폰·적립금 결제(모의)
  - 주문 후: 주문 조회·취소, **반품 신청**(사유별 환불액 미리보기), 구매확정, 리뷰, 상품 문의
  - **쿠폰함**: 쿠폰 받기, 결제 시 가장 할인이 큰 쿠폰 자동 선택, 1회 사용, 주문 취소 시 반환
  - **배송지 관리**: 최대 10개 저장, 기본 배송지 설정, 주문서에서 바로 선택
  - **🔔 알림함**: 재입고, 발송·배송완료, 문의 답변, 반품 완료 알림
  - **재입고 알림 신청**: 품절 상품 페이지에서 신청
  - **고객센터**: 자주 묻는 질문(검색 가능), 공지사항
- **셀러**
  - 셀러 등록, 사진 포함 상품 등록·수정·판매중지, 재고 관리
  - 주문 처리: 발주확인 → 송장 입력 → 배송완료
  - **반품 승인**: 환불·재고 복구가 자동으로 처리됨
  - 문의 답변, 매출·**정산** 대시보드, 새 주문·반품 요청 알림

데모 쿠폰: `WELCOME10` (가입 시 자동 지급, 10%, 최대 1만원), `PIKK5000` (3만원 이상 5천원), `SALE15` (5만원 이상 15%, 최대 1.5만원)

## 실행
빌드 과정이 없습니다. 이 폴더에서 정적 서버를 띄운 뒤 http://localhost:8080 으로 접속하세요.

```bash
python -m http.server 8080
```

## 구조
```
index.html, products.html, product.html, cart.html, checkout.html,
order-complete.html, mypage.html, seller.html, login.html, signup.html, help.html
css/style.css        디자인 시스템 (토큰, 컴포넌트, 반응형)
js/data.js           기본 상품·카테고리·쿠폰
js/store.js          localStorage 저장소 (상품, 장바구니, 주문·반품, 리뷰, 문의, 쿠폰함, 알림, 재입고, 배송지)
js/auth.js           회원가입·로그인 (데모)
js/layout.js         공통 헤더/푸터, 알림함, 상품 카드, 토스트, 모달
js/pages/*.js        페이지별 스크립트
```
