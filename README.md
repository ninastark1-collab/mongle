# 몽글 — 몽글몽글, 평생 가족

정성껏 키워주실 가족을 찾는 **책임 분양 하우스 데모**입니다. 순수 HTML/CSS/JavaScript로 만들었어요.

## 펫샵 구성
- **카테고리 8개:** 강아지 · 고양이 · 소동물 · 새 · 관상어·수생 · 파충류 · 곤충·절지 · 용품·사료
- **상품:** 반려동물 123마리(어른·노령 친구 6마리 포함)와 용품 7개
- **분양 정보:** 나이, 건강·접종, 평균 수명, 다 자란 크기, 키우기 난이도. 목록에서 [초보 추천만] 필터로 고를 수 있어요.
- **분양 규칙 (한국 법·소비자분쟁해결기준 기준)**
  - 생명은 택배로 보내지 않고 매장 방문 또는 펫택시로 직접 인계해요.
  - 결제할 때 책임 양육 동의가 필수예요.
  - 15일 건강보증이 있고, 단순 변심 반품은 안 돼요.
- **판매하지 않는 종:** CITES(국제 거래 규제) 대상종과 생태계교란종은 다루지 않아요. 브리더(셀러)가 동물을 등록할 때도 같은 안내가 나와요.
- **사진:** [Unsplash 무료 라이선스](https://unsplash.com/license) 실사 이미지를 그대로 불러와 써요.

## 책임 분양 기능
- **먼저 만나보기:** 신청서 작성 → 만남 예약(방문·화상) → 분양자 승인 → 분양비 결제 → 인계. 결제 전에는 인계할 수 없고, 분양자는 정중히 거절할 수 있어요.
- **아이별 정보:** 태어난 곳·부모, 생일, 예방접종 기록과 다음 접종일, 유전 질환 검사, 동물등록, 중성화 정보를 보여줘요.
- **평생 비용:** 한 달 예상 비용(사료·병원·용품·보험)과 평생 예상 비용을 보여주고, 신청할 때 확인 체크를 받아요.
- **돌아오기 약속:** 함께하기 어려워지면 마이페이지에서 재입양 상담을 신청해요.
- **건강 캘린더:** 입양 후 첫날부터 한 달까지의 일정과 다음 접종을 알림함으로 알려줘요.
- **입양 후 가이드:** 분류별 첫 일주일 가이드, 동물등록·펫보험 안내를 담았어요.
- **나와 맞는 친구 퀴즈:** 가족·집·혼자 있는 시간·교감 방식·소리·알레르기·예산·함께할 기간 등 10가지 질문으로 맞는 친구를 % 와 이유·주의점까지 추천해요. 원하는 사람만 화면 구석의 떠 있는 버튼, 상단 메뉴, 홈 배너에서 열 수 있고, 10문항을 한 화면에서 보고 골라요.
- **어른·노령 친구:** 재입양을 기다리는 어른 친구들과 나이 필터가 있어요.
- **보호소 입양 응원:** 국가동물보호정보시스템 링크와 기부 안내(데모)를 넣었어요.
- **새 가족 이야기:** 실제 입양 후기와 '예시 이야기'로 표시한 샘플을 함께 보여줘요.
- **준비물 한 번에 담기:** 분류별 맞이 준비물을 몽글바구니에 한 번에 담아요.

## 기능
- **구매자**
  - 상품 찾기: 목록·검색(자동완성/최근 검색어)·필터·정렬, 상품 상세, 찜
  - 결제: 장바구니(무료배송까지 남은 금액 표시), 쿠폰·적립금 결제(모의)
  - 주문 후: 주문 조회·취소, **반품 신청**(사유별 환불액 미리보기), 구매확정, 리뷰, 상품 문의
  - **쿠폰함**: 쿠폰 받기, 결제 시 가장 할인이 큰 쿠폰 자동 선택, 1회 사용, 주문 취소 시 반환
  - **배송지 관리**: 최대 10개 저장, 기본 배송지 설정, 주문서에서 바로 선택
  - **🔔 알림함**: 재입고, 발송·배송완료, 문의 답변, 반품 완료 알림
  - **재입고 알림 신청**: 품절 상품 페이지에서 신청
  - **고객센터**: 자주 묻는 질문(검색 가능), 공지사항
- **셀러**
  - 셀러 등록, 사진 포함 상품 등록·수정·판매중지, 재고 관리
  - 주문 처리: 발주확인 → 송장 입력 → 배송완료
  - **반품 승인**: 환불·재고 복구가 자동으로 처리됨
  - 문의 답변, 매출·**정산** 대시보드, 새 주문·반품 요청 알림

데모 쿠폰: `WELCOME10` (가입 시 자동 지급, 10%, 최대 1만원), `MONGLE5000` (3만원 이상 5천원), `SALE15` (5만원 이상 15%, 최대 1.5만원)

## 실행
빌드 과정이 없습니다. 이 폴더에서 정적 서버를 띄운 뒤 http://localhost:8080 으로 접속하세요.

```bash
python -m http.server 8080
```

## 주의
서버가 없는 데모입니다.
- 모든 데이터는 **방문자 각자의 브라우저(localStorage)** 에만 저장됩니다.
- 결제는 실제로 이루어지지 않습니다.
- 실제로 쓰는 비밀번호를 입력하지 마세요.

개선 기록은 [IMPROVEMENTS.md](IMPROVEMENTS.md)를 참고하세요.

## 분양비 기준
- 모든 아이의 분양비를 **국내에서 흔히 보이는 품종·종별 시세 범위 안**으로 다시 정했어요 (데모용 추정치, 지역·혈통·모색에 따라 다름).
- 친구 페이지의 **분양비 카드**에서 시세 범위와 이 아이의 위치, 가격 이유, 포함 항목(검진·접종·동물등록·건강보증 등)을 보여줘요.
- 성견·성묘는 30~50만 원대, 코리안 숏헤어는 25만 원으로 아기 품종견·품종묘보다 낮아요. 강아지 아기는 80만~220만, 품종묘 아기는 100만~280만 원 범위예요 (2025년 국내 시세 정리 자료 기준).
